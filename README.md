# Job Monitor

Персональная система мониторинга вакансий в сфере геодезии и строительства.

## О проекте

Job Monitor — разрабатываемое некоммерческое приложение для индивидуального поиска работы в Москве и Московской области.

## Основные функции

- Получение актуальных вакансий через официальные API площадок.
- Поиск по профессиональным направлениям.
- Фильтрация по региону и графику работы.
- Исключение вахтовых и архивных вакансий.
- Исключение повторяющихся объявлений.
- Формирование ежедневного персонального отчёта.
- Предоставление ссылок на оригинальные вакансии.

## Условия использования

Приложение предназначено исключительно для личного некоммерческого использования одним пользователем.

Автоматические отклики на вакансии и рассылки работодателям не предусмотрены.

## Конфиденциальность

Проект не предусматривает сбор резюме других соискателей, продажу информации или публичное распространение полученных через API данных.

Ключи API и токены авторизации не будут размещаться в публичном репозитории.

## Статус проекта

Приложение находится на этапе разработки и подключения официальных источников данных.
